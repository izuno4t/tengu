# AsIs / ToBe ギャップ分析

## 概要

現在の Tengu 実装と、実用的なコーディングエージェントとして必要な機能のギャップを整理する。

## 致命的ギャップ（実用に耐えない根本原因）

### G-001: エージェントループが単発実行

| 項目 | 内容 |
|------|------|
| AsIs | Plan→ToolSelect(1回)→Execute(1ツール)→FinalResponse の1パス |
| ToBe | LLM→ToolUse→Result→LLM→... を end_turn まで繰り返す自律ループ |
| 影響 | 複数ファイルの読み書き、段階的な問題解決が不可能 |
| 優先度 | **最高** |

### G-002: LLM ネイティブ tool_use を未使用

| 項目 | 内容 |
|------|------|
| AsIs | LLM にプレーンテキストで JSON を出力させ、自前パースで抽出 |
| ToBe | LLM API の tool_use / function_calling 機能を使用し、構造化されたツール呼び出しを受信 |
| 影響 | ツール呼び出しの信頼性が極めて低い。JSON パース失敗が頻発 |
| 優先度 | **最高** |

### G-003: 会話履歴（メッセージ配列）の欠如

| 項目 | 内容 |
|------|------|
| AsIs | LlmRequest は単一の prompt 文字列。過去の会話は文字列結合で雑に渡す |
| ToBe | Message[] 配列として role/content を構造化し、ツール結果も含めて正確に送信 |
| 影響 | マルチターン会話の品質が極端に低い。コンテキストが正しく伝わらない |
| 優先度 | **最高** |

## 重要ギャップ（基本機能の不足）

### G-004: Edit ツールの欠如

| 項目 | 内容 |
|------|------|
| AsIs | Write（全体上書き）のみ |
| ToBe | old_string → new_string の部分置換による Edit ツール |
| 影響 | ファイル編集で既存内容が全て消える危険性 |
| 優先度 | **高** |

### G-005: Bash（Shell）ツールの機能不足

| 項目 | 内容 |
|------|------|
| AsIs | Command::new で単純実行。タイムアウトなし、stderr 時はエラー扱い |
| ToBe | タイムアウト付き実行、stdout+stderr の統合出力、作業ディレクトリ指定 |
| 影響 | 長時間コマンドでハング、テスト実行結果が取得できない |
| 優先度 | **高** |

### G-006: Grep が正規表現非対応

| 項目 | 内容 |
|------|------|
| AsIs | `line.contains(pattern)` による単純文字列マッチ |
| ToBe | regex crate による正規表現マッチング |
| 影響 | コード検索の精度・柔軟性が著しく低い |
| 優先度 | **高** |

### G-007: Write が agent flow で実際に書き込まない

| 項目 | 内容 |
|------|------|
| AsIs | AgentRunner 内の Write は preview_write のみで、実際のファイル書き込みを行わない |
| ToBe | 承認後に実際にファイルに書き込む |
| 影響 | エージェントがファイルを変更できない（コーディングエージェントとして機能しない） |
| 優先度 | **最高** |

## 中程度ギャップ（利便性・拡張性）

### G-008: ストリーミング中のツール実行

| 項目 | 内容 |
|------|------|
| AsIs | ストリーミングはテキスト出力のみ。ツール呼び出しはストリーム外 |
| ToBe | ストリーミング応答内で tool_use を検出し、実行後に再送信 |
| 優先度 | 中 |

### G-009: コンテキストウィンドウ管理

| 項目 | 内容 |
|------|------|
| AsIs | 管理なし。会話が長くなるとトークン超過でエラー |
| ToBe | 自動コンパクション（古いメッセージの要約）またはトランケーション |
| 優先度 | 中 |

### G-010: MCP ツールのエージェントループ統合

| 項目 | 内容 |
|------|------|
| AsIs | MCP ツールは一覧表示のみ。エージェントループ内でのツール呼び出しに非対応 |
| ToBe | MCP ツールをビルトインツールと同列にエージェントループ内で呼び出せる |
| 優先度 | 中 |

### G-011: トークン/コスト表示

| 項目 | 内容 |
|------|------|
| AsIs | 使用量データは取得するが TUI 上で表示されない |
| ToBe | 各ターンのトークン使用量と累計を表示 |
| 優先度 | 低 |
